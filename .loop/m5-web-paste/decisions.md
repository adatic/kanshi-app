# m5-web-paste — レビュー指摘の採否

## 往復1（review-1.md）

| ID | 重要度 | 判定 | 理由・対応 |
|---|---|---|---|
| R1 | 中 | 採用 | 読みごとの欄は、どの読みでも出る違反を除いて求めているのに、残りが空だと「この読みなら違反なし」と表示していたため、どの読みでも出る違反（別の位置の国字など）があると一覧と矛盾していた。ReadingOptionView に clean（どの読みでも出る違反も含めて違反が一つもない）を足し、clean のときだけ「この読みなら違反なし」、そうでなければ「この読みで加わる指摘はありません（どの読みでも出る指摘は上の一覧にあります）」と表示する。両韻字と国字が共存するテストを追加。 |
| R2 | 中 | 採用 | 読みごとの欄は違反だけを抜き出していたため、一部の読みにだけ出る要確認（孤雁入群格の可能性など）が画面から消えていた。読みごとの指摘に要確認も含め、重み（✕・！）と規則名を添えて表示する。起句末を韻目の2つある字にした回帰テストを追加。 |
