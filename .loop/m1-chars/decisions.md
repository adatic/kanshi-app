## 往復1（review-1.md）

| ID | 重要度 | 判定 | 理由・対応 |
|---|---|---|---|
| R1 | 中 | 採用 | 指摘のとおり、平仄データに絞った後の候補数で一対多を判定していたため、「叙→敍・敘」のようにデータにある候補が1字だけの字が、どのレポートにも残っていなかった（175字）。絞る前の候補数で判定し、データにない候補も「平仄データにない」と書いて `ambiguous.txt` に残すようにした（395字）。`variants.json` の中身は変わらない。境界例を `scripts/test_build_data.py` に追加し、`npm test`（`npm run data:unit`）で走らせる。テストの追加中に、2字以上の見出しがあると並べ替えで落ちる潜在的な不具合も見つけて直した（今の OpenCC の表には該当なし）。 |
| R2 | 中 | 採用 | `data/corrections.json` を生成の入力に加えたのは意図した設計（元データを書き換えずに根拠つきで直すため。DATA_SOURCES.md に記載）で、完了条件の文言が実装に追いついていなかった。TASKS.md の完了条件を「`data/raw/` と、根拠つきの修正一覧 `data/corrections.json` だけから」に直した。完了条件は Claude Code が設定するもの（CLAUDE.md §7.1）で、仕様の変更ではない。 |

### 指摘以外の記述への対応

- 総評の「Vitest は未実行」は、読み取り専用の環境の制約による（CLAUDE.md §7.4 の注記のとおり）。手元で `npm test` を実行し、Python の単体テスト16件・再生成の一致・Vitest のデータ検査13件がすべて緑であることを確かめた。
