# m4-queries — レビュー指摘の採否

## 往復1（review-1.md）

| ID | 重要度 | 判定 | 理由・対応 |
|---|---|---|---|
| R1 | 中 | 採用 | 仮の字を、平仄データ・異体字の対応・国字に登録のない字から選んでいたが、詩の本文にある字を避けていなかった。本文にデータにない字（拡張B領域の先頭の字など）があると、仮の読みがそのマスにも当たり、離れたマスの判定が変わっていた。本文にある字も避けて選ぶようにした。指摘の再現例（起句4字目にその字を置き、転句1字目を問い合わせる）をテストにした。 |
| R2 | 中 | 採用 | 配置の判定で入力エラーを見ていなかったため、漢字以外の語を「置ける」と返していた。置いたマスに入力エラー（漢字以外・繰り返す字のない「々」）が出る場合と、語に「＿」を含む場合は status を invalid にし、位置と理由を errors に返す（公開APIの型 Placement に invalid と errors を足した）。英字・空白・読点を含む語、「＿」を含む語のテストを追加。 |
| R3 | 中 | 採用 | 配置の問い合わせに国字のテストがなかった。架空データの国字を1字差し替えた語で、既定では置けない（koku-ji の違反）、国字で続行するオプションでは置ける、をテストした（実装は変更不要だった）。 |
