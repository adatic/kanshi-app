# 人間の確認を求める事項（M3）

`golden/golden.test.ts` が `golden/exceptions.json` と `golden/questions.json` から生成する（`npm run golden:update`）。手で編集しない。

Claude Code は平仄・韻の正誤を記憶で判断しない（CLAUDE.md §0）。以下は、平水韻データと本文の版の違いからは分類を確定できない、または判断が仕様・データの出どころに関わる事項。

## 詩の分類

### q10 黃鶴樓送孟浩然之廣陵（李白）

```
故人西辭黃鶴樓  ●○○○○●○
煙花三月下揚州  ○○◎●●○○
孤帆遠影碧山盡  ○◎●●●○●
唯見長江天際流  ◎●◎○○●○
```

- 仮の分類：規則外の候補（拗体）
- 理由：4句すべてに定型との不一致があり、起句と承句の2字目がどちらも平で反法も守られていない。違反の位置の字は、平仄データで平仄が一つに決まる字ばかりで、本文の版の違いもこれらの位置に関わらない。データやロジックの誤りは見つからず、原詩が律詩の平仄に従わない作り（拗体）である可能性が高い。
  - 違反の位置の字の平仄データの読み：起句「辭」上平四支・「黃」下平七陽・「鶴」入声十藥、承句「花」下平六麻・「月」入声六月・「揚」下平七陽、転句「影」上声二十三梗、結句「見」去声十七霰・「江」上平三江・「天」下平一先・「際」去声八霽（いずれも読みは一つ）
  - 起句の2字目「人」上平十一真（平）、承句の2字目「花」下平六麻（平）
  - 本文の版の違い：唐詩三百首のファイルとは転句6字目（山／空。どちらも違反の位置ではない）、御定全唐詩とは違いなし
- 確認したいこと：この詩を拗体（律詩の平仄に従わない作り）として規則外と認めてよいか。

### q21 贈別·其一（杜牧）

```
娉娉褭褭十三餘  ◎◎●●●◎○
豆蔻梢頭二月初  ●●○○●●○
春風十里揚州路  ○○●●○○●
卷上珠簾總不如  ◎●○○●◎◎
```

- 仮の分類：規則外の候補（不粘）
- 理由：承句と転句の2字目の平仄が違い、粘法が守られていない。2字目の字は平仄データで読みが一つに決まり、本文の版の違いもこの位置に関わらない。ほかの規則の違反はなく、原詩が不粘の作りである可能性が高い。
  - 承句の2字目「蔻」去声二十六宥（仄。読みは一つ）、転句の2字目「風」上平一東（平。読みは一つ）
  - 本文の版の違い：唐詩三百首のファイルとは起句3・4字目（褭／嫋）と転句4字目（里／裏）、御定全唐詩とは転句4字目（里／裏）。いずれも2字目ではない
- 確認したいこと：この詩を不粘（拗体）として規則外と認めてよいか。

### q32 滁州西澗（韋應物）

```
獨憐幽草澗邊生  ●○○●●○○
上有黃鸝深樹鳴  ●●○○◎●○
春潮帶雨晚來急  ○○●●●○●
野渡無人舟自橫  ●●○○○●◎
```

- 仮の分類：規則外の候補（不粘）
- 理由：承句と転句の2字目の平仄が違い、粘法が守られていない。転句・結句の定型との不一致は、詩格（平起式・首句入韻）の後半の2句を逆の起式で作っていることから生じるもので、転句（挟み平を含む）と結句はそれぞれ単独では二四不同・二六対・下三連・孤平の違反がない。2字目の字は平仄データで読みが一つに決まり、本文の版の違いはない。原詩が不粘の作りである可能性が高い。
  - 承句の2字目「有」上声二十五有（仄。読みは一つ）、転句の2字目「潮」下平二蕭（平。読みは一つ）
  - 転句・結句には、定型との不一致と反法・粘法のほかに違反がない（data/reports/golden.md）
  - 本文の版の違い：唐詩三百首のファイル・御定全唐詩とも違いなし
- 確認したいこと：この詩を不粘（拗体）として規則外と認めてよいか。

### q42 回鄉偶書·其一（賀知章）

```
少小離家老大回  ●●◎○●●◎
鄉音難改鬢毛衰  ◎○◎●●○○
兒童相見不相識  ◎○◎●◎◎●
笑問客從何處來  ●●●◎○●○
```

- 仮の分類：規則外の候補（通韻）、または平仄データの不足
- 理由：押韻字は起句「回」・承句「衰」・結句「來」。平仄データでは「回」「來」は上平十灰、「衰」は上平四支だけで、承句だけが別の韻目になる（エンジンは結句を承句と比べて違反を出している）。手元のもう一つの資料（ウィキソース「平水韻」2006年版、2008年に差し替えられる前の別の一覧）でも「衰」は上平四支だけに載っている。手元の資料からは、データの誤りとは言えない。
  - 押韻字の平仄データの読み：「回」上平十灰・去声十一隊、「衰」上平四支、「來」上平十灰
  - ウィキソース「平水韻」版96365（2006年）：「衰」は「上平,四支」の一覧にだけある
  - 本文の版の違い：唐詩三百首のファイルとは承句3字目（難／無）、御定全唐詩とは起句4字目（家／鄉）。押韻字ではない
- 確認したいこと：「衰」に上平十灰の読みがあるとする信頼できる韻書があれば、出典つきで平仄データに加える（data/corrections.json）。なければ、この詩を通韻として規則外と認めてよいか。

## そのほかの判断事項

### 1. 本文の取得元（全唐诗 poet.tang）でよいか

唐詩三百首のファイルの本文は簡体字からの機械変換の誤りを含むため、chinese-poetry の繁体字の全唐詩から照合して本文を取った。2種類の全唐詩を比べると、御定全唐詩には変換の誤りに見える字が5か所あり（乾→幹、闌干→闌幹 ×2、御柳→禦柳、鬚→須）、全唐诗/poet.tang ではすべて正しい字だった。そこで本文は全唐诗/poet.tang から取った（詳しくは DATA_SOURCES.md の 6、data/reports/golden-input.md）。

- このままでよい
- 別の資料を使う（資料を指定してください）

### 2. 唐詩三百首の「樂府」の4句×7字の詩をゴールデンに含めるか

唐詩三百首のファイルの分類「樂府」に、4句×7字の詩が8首ある（王之渙「涼州詞」、王昌齡「出塞」、王維「渭城曲」「秋夜曲」、李白「清平調」三首、無名氏「金縷衣」）。今は分類「七言絕句」の51首だけをゴールデンにしている。8首のうち2首は照合先が決まらない（王維「秋夜曲」は全唐詩では王涯の作、李白「清平調 其三」は本文の違う候補が同点）。また王維「渭城曲」は全唐诗/poet.tang の本文に「謂城」の誤字がある。

- 含めない（今のまま）
- 照合先が決まった6首を含める（渭城曲の誤字の扱いも決める）

### 3. 平仄データにない字を、Unihan の異体字でさらに補うか

ゴールデンの51首で、平仄データにない字が10種類あった（data/reports/golden.md）。このうち6字（壻→婿、爲→為、猨→猿、鏁→鎖、掃→埽、牀→床）は、Unihan の kSemanticVariant（意味が同じで置き換えられる字）をたどると平仄データの字につながる。M1 の判断 (c) では、Unihan で補うのは OpenCC の対応表に載っている字に限ったため、これらは補われていない。残りの4字（啼・遍・葡・迴）は、どうたどっても平仄データにない。補うと、q08（朱慶餘「近試上張水部」）の転句末「壻」が仄（婿：去声八霽）として判定でき、挟み平が確定する。

- 補わない（今のまま。データにない字は要確認）
- OpenCC の表にない字にも、Unihan の同じ3つの欄で補う（M4 の前に小さなタスクとして行う）
